## Dataset

This project uses the **Salinas hyperspectral dataset**.

Source:
Hyperspectral Remote Sensing Scenes
http://www.ehu.eus/ccwintco/index.php/Hyperspectral_Remote_Sensing_Scenes

Files required:
- Salinas.mat
- Salinas_gt.mat

Due to file size, the dataset is not included in this repository.
Please download it from the source and place the files in this folder.
